批量导入账号

支持 JSON 数组、逐行 JSON 或简单文本。导入时可附带默认代理组和默认权重。

若条目里没有 `id`，系统会优先使用 `email`、`clientId` 或自动生成 ID。

账号与代理分配

按顺序把多个账号分配到多个代理组。一个账号只能归属一个代理组，一个代理组可挂多个账号。

分配时会按顺序轮转代理组；已存在代理组绑定的账号会被新结果覆盖。
